## 1. Introduction

The Insulin Pump Control System is a Python-based educational software simulation.

This project demonstrates how software engineering concepts are used in safety-critical systems.

The system simulates basic operations such as input validation, safety monitoring, fault detection, alarm management and event logging.

## 2. Objectives

- To understand software engineering concepts.
- To validate user inputs.
- To monitor system safety.
- To detect system faults.
- To generate system alarms.
- To maintain event records.
- To demonstrate modular programming in Python.

## 3. Technologies Used

- Python 3
- Object-Oriented Programming
- File Handling
- Modular Programming
- GitHub

## 4. Project Modules

1. `main.py` - Main program of the system.
2. `pump_controller.py` - Controls the simulation workflow.
3. `input_validator.py` - Validates user inputs.
4. `safety_monitor.py` - Checks simulated safety conditions.
5. `pump_driver.py` - Handles simulated pump operations.
6. `display_manager.py` - Displays system messages and status.
7. `alarm_manager.py` - Manages simulated system alarms.
8. `event_logger.py` - Records system events.

## 5. Features

- System self-test
- Input validation
- Safety monitoring
- Fault detection
- Alarm management
- Event logging
- System status display
- Educational pump simulation
